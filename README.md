### 🧭 What I work on

- ⚡ **Performance Engineering** — k6 load-testing suites, custom Grafana/BlazeMeter-style reporting pipelines
- 🔐 **API & Security Testing** — OAuth2 / JWT / RBAC automation with REST Assured, Keycloak, FastAPI
- 🤖 **AI Test Automation** — multi-agent pipelines (AutoGen + MCP) that auto-generate QA test cases
- 🧪 **LLM Evaluation** — DeepEval-based evals for RAG pipelines, agents & multi-turn chatbots (faithfulness, bias, tool-correctness)
- 📱 **Mobile & Web Automation** — Appium, Playwright, Page Object Model frameworks
- 🔁 **CI/CD for QA** — GitHub Actions pipelines that validate, lint, and report on every PR
